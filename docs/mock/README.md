# 栖衡 · 双端静态 Demo v0.1

用于页面与流程评审，不是已批准的产品实现。Apple / Airbnb 仅作为留白、层次与亲和感的视觉方向；没有复制外部项目代码、品牌素材或图表。

## 打开与演示

用现代浏览器打开 [index.html](./index.html)，无需安装、构建或联网。也可在项目根目录使用已有 Python：

```powershell
python -m http.server 8080 --bind 127.0.0.1 --directory .\docs\mock
```

访问 `http://127.0.0.1:8080`。端口被占用时换一个端口，不终止其他服务。

### 推荐路线：酒店 A

1. 顾问端进入云栖城市酒店，查看资料核对；没有代确认权限。
2. 切换业主端 → 资料与确认，逐项确认售出房晚和收入。
3. 查看阶段性结果：OCC 70%、ADR 280 元、RevPAR 196 元。
4. 切回顾问端 → OTA 情景，显式填写假设进行比较。例如新增收入 30,000 元、额外佣金 2 个百分点、新增预算 5,000 元、新增酒店折扣 10,000 元，情景渠道净收益为 303,608 元，基线为 298,464 元。这不是酒店利润或收益预测。
5. 报告与跟进 → 生成初稿 → 审核通过 → 模拟交付。
6. 切回业主端 → 报告与反馈，查看交付版本、打印带演示水印的页面、填写虚构行动记录。
7. 修改确认数据后，旧报告快照保持不变；必须由顾问生成并审核交付新版本。退回后的修订也产生新版本。

### 其他案例

| 酒店 | 用途 |
|---|---|
| B：溪岸小筑 | 邀请待接受、资料未知；业主可模拟接受或过期，顾问未获授权前不展示经营资料 |
| C：观澜商旅酒店 | 基础数据已确认，提供两个合成对照周期；真实可比性规则未批准，不宣称达到 L2 或输出趋势判断 |
| D：山隐度假酒店 | 顾问授权已撤销，顾问经营页面受限；业主仍可查看自己的演示资料 |

业主端还提供首诊表单与授权状态。首诊表单仅演示分流，不自动创建诊断或改变预设在营案例；筹备中和阶段未知均提示人工评估。

## 数据与边界

- 全部酒店、凭证、收入、佣金和反馈均为合成数据。金额为人民币；没有住客或真实酒店资料，不接收文件。
- 数据定义和计算位于 [demo-model.js](./demo-model.js)。A/C 的 30 天、100 间房、3,000 可售房晚、2,100 售出房晚、588,000 元收入是人工构造的自洽案例，不是行业统计。
- 数值量级参考：[华住 2024 年业绩发布](https://www.prnewswire.com/news-releases/h-world-group-reports-fourth-quarter-and-2024-full-year-financial-results-302407070.html)中的 Legacy-Huazhu 全年入住率 81.2%。集团样本不作为独立酒店目标、同行基线或诊断阈值；Demo 未导入其数据集。
- 未知保留为 `null`；未确认字段不用于指标计算。周期汇总不制造逐日趋势，挂牌价不替代 ADR。
- 渠道基线采用已扣酒店折扣的收入 `R`，净收益为 `R-C-A`；情景仅扣新增折扣一次，明确假设佣金基数为折后收入。全部假设需手工输入；加佣不自动推导新增收入。
- 提价、竞品可比性、佣金流量、风险阈值仍关闭。没有真实 OCR、身份验证、服务端鉴权、PMS、支付、消息发送或自动经营动作。
- 报告编号带 `DEMO`，交付只是本地状态，打印只打开浏览器预览，不表示 PDF 已生成、下载成功或客户已接收。生产报告水印、下载日志和权限需另行实现。
- 静态前端可被查看和修改，角色切换不是安全边界。不能用于真实数据隔离或业务验收。

## 本地进度与验证

使用 `localStorage` 的独立键 `revenue-diagnostic-demo-v1` 保存演示进度。不同浏览器或访问地址的进度不共享；本地文件的存储行为取决于浏览器。不支持存储时页面明确告警。不要填写任何真实或敏感资料。

顶部「重置演示」经确认仅恢复本 Demo 的数据，不清空其他站点或浏览器配置。

在项目根目录运行无需外部依赖的模型测试：

```powershell
node --test .\tests\mock\demo.test.cjs
```

测试覆盖未知值、零房晚、授权状态、字段确认、审核与交付门禁、报告快照版本和情景计算。浏览器评审应另外检查双端切换、移动端布局、表单操作和刷新后的本地进度；合成测试不替代真实脱敏酒店案例验收。
